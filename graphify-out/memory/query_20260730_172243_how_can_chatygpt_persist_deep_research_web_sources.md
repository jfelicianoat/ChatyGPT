# Q: How can ChatyGPT persist Deep Research web sources without inventing unsupported Broker agent iteration fields?

## Answer

Use the stable completed Markdown result as evidence. For deep_research tasks only, parse actual Markdown links and bare HTTP(S) URLs, normalize and deduplicate them, remove fragments, reject credentials and non-web schemes, cap at 50, and materialize them in the existing citations table in the same terminal-state transaction. Display them as web sources and reuse existing Markdown/Obsidian export. Do not infer searches or reads from technical phases when result.agent has no documented stable iteration schema.
